## 证据状态

每项现状能力使用以下状态，不以“代码存在”代替生产证明：

| 状态 | 含义 |
|------|------|
| Implemented | 在指定源码版本中存在实现 |
| Deployed | 在指定环境和配置版本中已部署 |
| Enforced | 不能通过旁路绕过 |
| Verified | 已通过冻结的正向、负向和故障测试 |
| Unverified | 缺少上述任一证据，不作已具备结论 |

内部证据至少记录源码或镜像摘要、部署环境、配置版本、验证日期、责任人和证据位置。对外候选至少记录版本、许可证或 Edition、部署形态、官方来源和核验日期。
